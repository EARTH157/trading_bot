# Trading Safety Rules

1. **โหมดการเทรดเริ่มต้น (Default Mode)**
   - โหมดเริ่มต้นของระบบต้องเป็น `PAPER_TRADING` หรือ `BACKTEST` เสมอ
   - ห้ามเปลี่ยนโหมดเป็น `LIVE_TRADING` ในโค้ดโดยพลการ ต้องให้ผู้ใช้งานระบุความยินยอมผ่าน Config หรือ UI อย่างชัดเจน

2. **การป้องกันเงินทุน (Capital Protection)**
   - ไม่อนุญาตให้ใช้ Margin หรือ Leverage เกิน 1x เว้นแต่จะระบุในเงื่อนไขการเทรด
   - มีกลไก Daily Max Loss Limit (หากพอร์ตขาดทุนถึงเกณฑ์ต่อวัน บอทต้องหยุดเทรดทันที)
   - ออเดอร์ทุกตัวต้องผูก Stop Loss Price ไว้เสมอ

3. **การทดสอบความถูกต้องของคำสั่ง (Order Validation)**
   - ต้องตรวจสอบยอดเงินคงเหลือ (Buying Power) ก่อนส่ง Order ทุกครั้ง เพื่อป้องกัน Order เด้ง Rejection
   - ป้องกัน Duplicate Orders (ส่งคำสั่งซ้ำซ้อนในเวลาเดียวกัน)
